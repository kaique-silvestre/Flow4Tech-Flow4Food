## Glossary
- **comanda**: Open bill of a unit; has a display number, optional table, responsible waiter, `versao` for optimistic concurrency.
- **rodada**: A set of items sent together with a client-generated id (idempotent); can be undone inside a short window.
- **versao**: Optimistic-concurrency counter on the comanda; a stale value answers 409 with the current one.
- **turno**: A cash register shift of one operator in one unit (opens with a float, closes with a count).
- **dia operacional**: The unit's operating day from `IOperatingDayResolver`, not UTC.
- **[A] / [L]**: [A] = audited action; [L] = permission with a limit decided by the authorization engine.
- **unit of work**: `IUnitOfWork.ExecuteAsync`: one tenant transaction holding decision, state change, audit and outbox.
- **fila**: Client-side pending-actions queue (localStorage `f4.fila.v1`) sent in order with back-off; the server is idempotent.
