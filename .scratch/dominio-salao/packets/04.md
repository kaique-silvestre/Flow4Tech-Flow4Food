## Glossary
- mesa: optional physical table of a unit; status (livre, ocupada) is computed from open comandas, never stored.
- permissao: catalog constant `resource:action` (hyphens in code), declared in a [PermissionCatalog] class; every route declares one and asks the single engine IAuthorizationEngine.DecidirAsync.
- RLS: row level security forced on every tenant table with the exact isolation policy on app_organizacao_id().
- Language: code, tests and ticket in English identifiers where the codebase does; API/route names and permission/audit/event names follow the Portuguese vocabulary already used (`comanda`, `rodada`, `caixa`); UI copy in Portuguese.
