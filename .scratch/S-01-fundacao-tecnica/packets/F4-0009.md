> §5.4 items 1-6: evaluate Cedar (or equivalent) against three real cases: discount with limit, courtesy with daily cap evaluated in the same transaction, manager only on unit 2; also explicit deny beats allow, default deny, unknown permission denies; compare on expressiveness, ASP.NET integration, performance, testability, dependency risk; deliver a single decision interface independent of the choice; record the decision.
> 03-seguranca S8: single decision point; input is who, what (`resource:action`), where (organization, unit, object) and context (value, %, time, device, session type); deny > allow > default deny; limits evaluated on the real value of the operation, not what the client says.

## Glossary
- **decision engine**: The single authorization decision point: Decidir(who, resource:action, where, context).
- **tenant**: One organization (customer). Isolation between tenants is the top security priority.
