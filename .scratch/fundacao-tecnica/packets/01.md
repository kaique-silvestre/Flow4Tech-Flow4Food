## Glossary
- **Kernel**: Small stable shared module: organization/unit context, money and id types, decision engine contract, event bus, audit, clock.
- **module**: A bounded domain unit with a small public API; other modules may only use that API or its events.
- **ADR**: Architecture Decision Record in docs/adr/.
