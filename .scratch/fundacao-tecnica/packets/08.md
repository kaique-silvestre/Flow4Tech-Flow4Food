## Glossary
- **outbox**: Domain events written in the same transaction as the state change, delivered later by a dispatcher.
- **organization context**: The organization id resolved from the authenticated token, never from a client parameter; set per transaction in the database.
- **RLS**: PostgreSQL row-level security: the database itself refuses rows of another organization.
