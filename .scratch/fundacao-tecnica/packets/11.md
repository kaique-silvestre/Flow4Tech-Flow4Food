## Glossary
- **app credential**: Database role used by the running application: not table owner, cannot bypass RLS. Migrations use a separate credential.
- **RLS**: PostgreSQL row-level security: the database itself refuses rows of another organization.

## Seams
Pipeline: the deploy itself. Post-deploy smoke: readiness OK and an isolation check using the application credential in `staging`.
