## Glossary
- rodada: set of items sent together; has a client-generated id (idempotency); can be undone within 8 seconds by whoever sent it.
- item: product + quantity + note launched in a comanda, with product name and price frozen at launch; states lancado, cancelado.
- barra de rodada (round bar): sticky bar showing staged, unsent items with the one accent button to send; after sending it holds the 8-second undo.
- versao: optimistic concurrency counter on the comanda; a stale version returns 409 with the current one.
- Language: code, tests and ticket in English identifiers where the codebase does; API/route names and permission/audit/event names follow the Portuguese vocabulary already used (`comanda`, `rodada`, `caixa`); UI copy in Portuguese.
