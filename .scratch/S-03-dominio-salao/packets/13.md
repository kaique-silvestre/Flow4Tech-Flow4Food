## Glossary
- fila de acoes pendentes: visible client queue of writes waiting for the network, sent in order and retried without duplicating.
- idempotency: the client generates the id (UUID v7) of a rodada or a payment; the server answers repeats with the same result and a single row.
- versao: optimistic concurrency counter on the comanda; a stale version returns 409 with the current one.
- Language: code, tests and ticket in English identifiers where the codebase does; API/route names and permission/audit/event names follow the Portuguese vocabulary already used (`comanda`, `rodada`, `caixa`); UI copy in Portuguese.
