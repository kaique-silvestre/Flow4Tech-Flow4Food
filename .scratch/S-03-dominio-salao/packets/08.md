## Glossary
- barra de rodada (round bar): sticky bar showing staged, unsent items with the one accent button to send; after sending it holds the 8-second undo.
- fila de acoes pendentes: visible client queue of writes waiting for the network, sent in order and retried without duplicating.
- Language: code, tests and ticket in English identifiers where the codebase does; API/route names and permission/audit/event names follow the Portuguese vocabulary already used (`comanda`, `rodada`, `caixa`); UI copy in Portuguese.

## Commands
- dev: `docker compose up --build` (PostgreSQL + API; `docker compose down` to stop)
- port: API http://localhost:8080 (`/health/live`, `/health/ready`), PostgreSQL localhost:5432
- lint/format: `dotnet format backend/Flow4Tech.sln` (check only: add `--verify-no-changes`)
- typecheck: `dotnet build backend/Flow4Tech.sln && pnpm -r typecheck`
- test: `dotnet test backend/Flow4Tech.sln` (Docker must be running: Testcontainers); one project: `dotnet test backend/tests/<Project>/<Project>.csproj`
- client tests: `pnpm -r --if-present test`
- contract (after any route/DTO change; commit both outputs): `dotnet build backend/src/Api/Flow4Tech.Api.csproj -p:GenerateContract=true && pnpm --filter @flow4tech/api-client generate`
- catalogs: `UPDATE_PERMISSION_CATALOG=1 dotnet test backend/tests/Architecture/Flow4Tech.Architecture.Tests.csproj` (permissions), `UPDATE_AUDIT_CATALOG=1 ...` (audit), `UPDATE_SETTINGS_CATALOG=1 ...` (settings)
- isolation/RLS: `dotnet test backend/tests/Isolation/Flow4Tech.Isolation.Tests.csproj` (Docker required)
- never commit values; config by environment variables only.
