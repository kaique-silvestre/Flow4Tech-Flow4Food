## Ticket
**What to build:** The cashier receives money for a comanda (partial or full), sees the change, and the comanda closes only when the balance is zero. A service fee (default 10%, frozen on opening) is included; removing it needs a permission and is audited. The cash received enters the open shift's expected amount. Closed comandas accept nothing more.

## Glossary
- saldo: consumption (launched items) + service fee - amount applied by payments; the comanda closes only at zero.
- troco: change = amount received - amount applied, never negative.
- taxa de servico: service fee, a percentage per unit (default 10, 0 to 20), frozen on the comanda when opened; removing it needs a permission and is audited.
- turno (shift): a cash register session of one operator in one unit, opened with a float and closed with a count.
- idempotency: the client generates the id (UUID v7) of a rodada or a payment; the server answers repeats with the same result and a single row.
- unit of work: IUnitOfWork.ExecuteAsync opens ONE tenant transaction shared by DecidirAsync, the state change, the audit record and the outbox event.
- outbox: domain events written with OutboxWriter.AddAsync on the same transaction as the state change.
- permissao: catalog constant `resource:action` (hyphens in code), declared in a [PermissionCatalog] class; every route declares one and asks the single engine IAuthorizationEngine.DecidirAsync.
- Language: code, tests and ticket in English identifiers where the codebase does; API/route names and permission/audit/event names follow the Portuguese vocabulary already used (`comanda`, `rodada`, `caixa`); UI copy in Portuguese.
